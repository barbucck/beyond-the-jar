# Beyond the Jar

Beyond the Jar is a personal application for tracking real-world missions drawn from a physical jar.

The application will record revealed missions, their progress and completion, overall category progress, and rewards unlocked after completing mission milestones.

## Current status

The project is currently in the UX/UI design phase. Application code has not been scaffolded yet.

The planned stack is Angular, NestJS, SQLite, Tailwind CSS, and pnpm.
